ResQ Route – Optimized Route Planner for Emergency Vehicles

Project Overview

ResQ Route is a web-based emergency vehicle route planning simulation designed to identify optimized routes from an emergency location to suitable hospitals.

It uses graph algorithms and data structures to demonstrate efficient route planning while considering traffic conditions and road blockages.

Features

- Find optimized routes using Dijkstra's Algorithm.
- A* Search Algorithm for route optimization.
- AVL Tree for hospital specialty searching.
- Priority Queue for emergency prioritization.
- Traffic simulation.
- Road blockage simulation.
- Ambulance route animation.
- Hospital information and route comparison.
- Interactive city map visualization.

Technologies Used

- HTML
- CSS
- JavaScript
- Data Structures and Algorithms

Algorithms and Data Structures

- Dijkstra's Algorithm: Finds the shortest path.
- A Algorithm:* Finds an optimized path using a heuristic.
- AVL Tree: Supports efficient hospital searching.
- Priority Queue: Demonstrates priority-based emergency handling.

How to Run

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open "index.html" using Live Server.
4. Select the starting location and patient location.
5. Choose a route-finding algorithm.
6. Click Find Optimized Routes.
7. Use the simulation controls to test traffic and road blockages.

Project Objective

To demonstrate how data structures and algorithms can support emergency vehicle route planning through an interactive simulation.

Disclaimer

This is an academic simulation project. It does not provide real-time GPS navigation, live traffic information, or actual emergency dispatch services.
